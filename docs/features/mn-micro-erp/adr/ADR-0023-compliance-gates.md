# ADR-0023: Нийцлийн хаалга — СЯ-ны батлагдсан программын жагсаалт (Order 47), 10 жилийн хадгалалт, цахим гарын үсэг, ХХМХТХ (2021)

- **Төлөв:** Батлагдсан (Accepted)
- **Огноо:** 2026-10-06
- **Шийдвэр гаргагч:** Бүтээгдэхүүний эзэн, архитектурын баг, хууль зүйн зөвлөх
- **Холбогдох:** [02-architecture.md](../02-architecture.md) §8, §9.8, §10.6, §11.6, §12.8. [ADR-0007](./ADR-0007-append-only-ledger-reversal.md), [ADR-0013](./ADR-0013-hosting-in-mongolia-posapi-operator.md), [ADR-0020](./ADR-0020-observability-otel-redaction.md), [ADR-0022](./ADR-0022-backups-pitr-archive-retention.md)

## Нөхцөл байдал

1. **Батлагдсан программ.** НББ-ийн тухай хуулийн Art. 17.1.11-ийн дагуу Сангийн яам батлагдсан НББ-ийн программын жагсаалтыг нийтэлдэг. Шаардлагыг **Order 47 (2018)** тогтоосон. Хяналтыг ММНБИ (MonICPA) хийдэг. Гол шаардлагууд:
   - хууль ба стандартад нийцэх;
   - журнал, ерөнхий дэвтэр, тайланг маягтаар гаргах;
   - **гүйлгээг нуух, далдлах, будлиулах, завших боломжгүй байх**.

   Бүрэн шалгах хуудас UNVERIFIED. Энэ бол **зах зээлд гарах хаалга** ([mn-accounting.md](../research/mn-accounting.md) §2.5).
2. **Хадгалах хугацаа.** Баримт, бүртгэл, тайланг ≥ 10 жил хадгална (§2.6).
3. **Цахим анхан шатны баримт.** **Цахим гарын үсгээр** баталгаажуулна (§2.7). Монпасс 2025-05-22-оос дэмжигдэхээ больсон. Гэрэгэ, Инфосерт, Тридум бол хувилбарууд. API ба үнэ UNVERIFIED.
4. **Хувь хүний мэдээлэл хамгаалах тухай хууль** (2021-12-17, хүчин төгөлдөр 2022-05-01):
   - зорилго, зөвшөөрөл;
   - аюулгүй байдлын арга хэмжээ;
   - зөрчлийг субъектод **даруй** мэдэгдэх (art. 22.2);
   - жилийн бүртгэлийг Хүний эрхийн үндэсний комисст хүргүүлэх (art. 22.6);
   - гадаад руу дамжуулахыг хязгаарлах (art. 14.1);
   - хуулбар авах эрх (portability).

   Хуулийн зүйл заалт дунд зэргийн итгэлтэй ([mn-integrations-market.md](../research/mn-integrations-market.md) §7).

## Шийдвэр

**A. Order 47-ийн нийцлийн матрицыг хөтөлнө.** Файл: `docs/features/mn-micro-erp/compliance/order47-matrix.md`. Шаардлага бүрт архитектурын хяналт ба тестийн нотолгоог холбоно. Анхны хэсэг:

| Шаардлага (extract) | Архитектурын хяналт | Нотолгоо |
|---|---|---|
| Гүйлгээг нуух, засах боломжгүй | Append-only ledger + guard trigger + REVOKE ([ADR-0007](./ADR-0007-append-only-ledger-reversal.md)). Hash chain. Буцаалт зөвхөн шинэ бичилтээр | CI-ийн immutability тест. Шөнийн hash шалгалт. "Бүрэн бүтэн байдлын тайлан" |
| Давхар бичилт, accrual | Posting engine Σ = 0. Deferred constraint trigger | Property test, golden scenario |
| Дараалсан дугаар | Цоорхойгүй цуврал ([ADR-0008](./ADR-0008-gapless-numbering.md)). `entry_no`-гийн цоорхойг шалгах | Concurrency test |
| Журнал, ерөнхий дэвтэр, тайлан маягтаар | Order 100-ийн бүртгэлүүд. Маягт А-ийн загвар өгөгдөл ([ADR-0019](./ADR-0019-reporting-questpdf-closedxml.md)) | PDF snapshot тест |
| Хэн, хэзээ, юу өөрчилсөн | `gl_register`, `audit.row_change`, `audit.security_event` | Аудитын лог экспорт |
| Анхан шатны баримтгүйгээр бичилт хийхгүй (REQ-ACC-07) | Posting баримт эх баримттай байна. Гар журналд хавсралт ба батлагч заавал (тохиргоо) | Domain тест |
| Монгол хэл, MNT, хуанлийн жил | [ADR-0005](./ADR-0005-tenant-vs-company.md), [ADR-0017](./ADR-0017-i18n-mongolian-first.md) | UI ба PDF тест |
| Үе хаах | OPEN / SOFT_LOCKED / CLOSED / HARD_LOCKED. DB trigger | Integration тест |

- Order 47-ийн бүрэн текст ба үнэлгээний журмыг **хөгжүүлэлт эхлэхээс өмнө** олж авна. Матриц GA-ийн release checklist-ийн нэг хэсэг.

**B. 10 жилийн хадгалалт.**
- Ledger ба аудитын лог DB-д тенант идэвхтэй байх хугацаанд бүтнээр хадгалагдана.
- Жилийн архивын багц 10 жилийн retention-тэй ([ADR-0022](./ADR-0022-backups-pitr-archive-retention.md)).
- Хадгалах хугацаанд байгаа өгөгдлийг хэрэглэгчийн UI-аас устгах боломжгүй. Тенантын purge зөвхөн тусгай журмаар хийгдэнэ.
- Хадгалах хугацааны параметр (default 10 жил) нь `platform.company_setting`-д байна.

**C. Цахим гарын үсэг (2 шаттай).**
- **MVP:** `platform.document_signature` нь дараах зүйлсийг хадгална:
  - баримтын canonical PDF-ийн SHA-256;
  - гарын үсэг зурсан хүний үүрэг (бэлтгэсэн / баталсан / хянасан: захирал, ерөнхий нягтлан, кассчин, нярав);
  - хэрэглэгч, цаг, MFA-ийн нотолгоо.

  Тамганы зураг тохируулж болох хэвлэх элемент.
- **GA (СЯ-ны жагсаалтад орохоос өмнө):** `ISignatureProvider` адаптераар Гэрэгэ, Инфосерт эсвэл Тридумын PKI үйлчилгээгээр **PAdES** гарын үсэг зурна. Хамрах зүйлс:
  - posted нэхэмжлэх (ТМ-1);
  - кассын баримт (МХ-1/2);
  - санхүүгийн тайлан;
  - жилийн архивын багцын manifest.

  Гарын үсэг зурсан PDF object storage-д хадгалагдана.
- Провайдерын API ба үнэ тодорхой болмогц тусдаа ADR-аар провайдерыг сонгоно.

**D. Хувь хүний мэдээлэл (ХХМХТХ 2021)** ([02-architecture.md](../02-architecture.md) §10.6):
- **Ангилал.** PII-ийн каталог (`docs/.../compliance/pii-catalog.md`) ба кодын data classification attribute ашиглана.
- **Хамгаалалт:**
  - хувь хүний регистр ба `civil_id`-ийг AES-256-GCM-ээр шифрлэж, HMAC-аар хайна;
  - жагсаалтад маскална;
  - задлах эрх (`ERP PII UNMASK`) логтой.
- **Хадгалахгүй, лог руу гаргахгүй:** `qrData`, `lottery`, хувь хүний регистр ([ADR-0020](./ADR-0020-observability-otel-redaction.md)).
- **Монголоос гаргахгүй:** бүх өгөгдөл, нөөц, лог ([ADR-0013](./ADR-0013-hosting-in-mongolia-posapi-operator.md)).
- **Гэрээ.** Тенант бүртэй **өгөгдөл боловсруулах гэрээ (DPA)** байгуулна. Тенант = хянагч, бид = боловсруулагч.
- **Зөвшөөрөл.** Маркетинг зэрэг татвар, НББ-ээс өөр зорилгоор боловсруулахад `parties.consent` бүртгэнэ.
- **Субъектын эрх:** хуулбар авах (экспорт), засах. Устгах хүсэлт ирвэл хадгалах хугацаа дууссаны дараа нэргүй болгоно.
- **Зөрчил гарвал:** runbook; `audit.security_incident`; субъектод даруй мэдэгдэх; жилийн бүртгэл.
- **Нөлөөллийн үнэлгээ** (art. 23): автомат шийдвэр гаргах функц (жишээ нь зээлийн оноо) нэмэх бол түүнээс өмнө хийнэ.

**E. Хариуцлага.** Нийцлийн эзэн нь бүтээгдэхүүний эзэн. Улирал бүр матрицыг хянана. Хуулийн өөрчлөлтийг (2027 оны багц, Order 361/347-ийн шинэчлэл) [ADR-0021](./ADR-0021-effective-dated-parameters.md)-ийн дагуу параметр болгон оруулна.

## Үр дагавар

**Эерэг:**
- Нийцлийн шаардлага бүр архитектурын тодорхой хяналт ба тесттэй холбогдоно.
- СЯ-ны жагсаалтад орох нотолгоо хөгжүүлэлтийн явцад хуримтлагдана.

**Сөрөг ба эрсдэл:**
- **Order 47-ийн бүрэн текст UNVERIFIED.** Шинэ шаардлага гарч ирж, хуваарьт нөлөөлж болно.
  - Бууруулах арга: текстийг эрт олж авах; ММНБИ-тэй урьдчилсан уулзалт хийх.
- **PKI гарын үсгийн провайдерын интеграцийн зардал ба хугацаа** UNVERIFIED.
- **Хувийн мэдээллийн хуулийн нарийн заалтыг** хуульчаар баталгаажуулна: DPO шаардлага, data localisation, хуулиар шаардсан боловсруулалтын үл хамаарах зүйл.

| Хувилбар | Давуу тал | Сул тал | Яагаад сонгоогүй |
