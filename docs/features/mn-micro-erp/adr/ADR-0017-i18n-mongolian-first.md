# ADR-0017: i18n — эхлээд монгол, дараа нь англи хэл

- **Төлөв:** Батлагдсан (Accepted)
- **Огноо:** 2026-10-06
- **Шийдвэр гаргагч:** Архитектурын баг, бүтээгдэхүүний эзэн
- **Холбогдох:** [02-architecture.md](../02-architecture.md) §1.3 (P11), §15. [ADR-0015](./ADR-0015-frontend-react-ag-grid.md), [ADR-0019](./ADR-0019-reporting-questpdf-closedxml.md)

## Нөхцөл байдал

- **Хуулийн шаардлага.** Нягтлан бодох бүртгэлийг **монгол хэлээр** хөтөлнө (НББ-ийн тухай хууль, Art. 7.1). Хэвлэмэл маягтууд (МХ-1/2, ТМ-1, Маягт А) монгол хэлээр, үсгээр бичсэн дүнтэй байна ([mn-accounting.md](../research/mn-accounting.md) REQ-ACC-04).
- **Англи хэл** гадаад эзэмшигч, хөрөнгө оруулагч, хөгжүүлэгчид хэрэгтэй.
- **Монгол кирилл үсэг.** Ө ба Ү үсэг бүх фонтод байдаггүй. Linux-ийн base image цөөн фонттой ирдэг.
- **Тоо форматлах.** Браузерийн ICU-ийн `mn` locale-ийн дэмжлэг UNVERIFIED. Монголбанк ба практикт `1,234,567.89` хэлбэр хэрэглэгддэг.
- **Монгол хэлний хайлт.** Морфологийн (stemming) дэмжлэг PostgreSQL-д байхгүй.

## Шийдвэр

1. **Хэл:** default `mn-MN`, нөөц хэл `en`. Хэрэглэгч тус бүр хэлээ сонгоно. **Хэвлэмэл хууль ёсны маягт ямагт монгол хэлээр** гарна. Англи хэлийг зөвхөн нэмэлт шошго болгон гаргаж болно.
2. **Текстийн эх үүсвэр:**
   - **SPA:** i18next, модуль бүрд JSON namespace (`web/src/locales/{mn,en}/{module}.json`).
   - **Сервер:** `.resx` (алдааны мессеж, имэйл, PDF-ийн шошго), `IStringLocalizer`.
   - **Алдаа:** тогтвортой код (`gl.period_closed`) + орчуулгын түлхүүр. Клиент кодоор орчуулна.
3. **Хэрэглэгчийн өгөгдөл:**
   - Хууль ёсны нэр (компани, данс, бараа, харилцагч) **монгол хэлээр** заавал байна.
   - Англи нэр (`name_en`) сонголттой.
   - Seed дансны төлөвлөгөө хоёр хэлтэй.
4. **Формат:**
   - **Тоо:** `1,234,567.89`. Өөрсдийн formatter-ээр (клиентэд `formatMoney`, серверт `MoneyFormatter`) гаргана. Браузерийн ICU-д найдахгүй.
   - **Огноо:** UI-д `2026.10.06`, хэрэглэгч тохируулж болно. API-д ISO `2026-10-06`.
   - **Цагийн бүс:** Asia/Ulaanbaatar.
5. **Үсгээр бичсэн дүн.** `MongolianAmountInWords` (сервер) нь төгрөг/мөнгө хэлбэрээр бичнэ. Жишээ: "Нэг сая хоёр зуун гучин дөрвөн мянга таван зуун жаран долоон төгрөг наян есөн мөнгө". Unit test 0–10¹² хүртэлх хил хязгаарын тохиолдлыг шалгана.
6. **Фонт.** Noto Sans ба DejaVu фонтыг container ба SPA-д (self-host) багтаана. PDF-д embed хийнэ. Тест: PDF-ээс задалсан текстэд "Өө Үү" үсэг зөв гарна.
7. **Эрэмбэ ба хайлт:**
   - Эрэмбэлэхэд ICU collation `"mn-x-icu"` ашиглана (PostgreSQL ICU-тэй build хийгдсэн байх шаардлагатай; CI шалгана).
   - Хайлтад `pg_trgm` (trigram) индекс, том жижиг үсгээс хамааралгүй.
8. **Орчуулгын процесс:**
   - Түлхүүр нь repo-д хадгалагдана.
   - CI шалгана: `mn` 100%, `en` 100% (release-ийн хаалга). Ашиглагдаагүй түлхүүрийн тайлан гарна.
   - Pseudo-localization тест урт мөрийг илрүүлнэ (монгол текст ихэвчлэн урт).
   - Нэр томьёоны толийг `docs/glossary.md`-д хөтөлнө (эхлэл нь [02-architecture.md](../02-architecture.md)-ийн Хавсралт А). BC-ийн монгол XLIFF-ийн нэр томьёотой нийцүүлнэ.

## Үр дагавар

**Эерэг:**
- Хуулийн шаардлага хангагдана.
- Хэрэглэгч бүтээгдэхүүнийг өөрийн хэлээр хэрэглэнэ.
- Англи хэл нь хөгжүүлэлт ба гадаад хэрэглэгчид тусална.

**Сөрөг ба эрсдэл:**
- **Орчуулгын ажил хоёр дахин** нэмэгдэнэ. CI-ийн хаалга орхигдсон орчуулгыг барина.
- **Монгол хэлний морфологийн хайлт байхгүй.** Trigram хайлт хангалттай гэж үзнэ.
- **ICU collation** хост бүрд ижил байх ёстой. DB-ийн default collation нь `C.UTF-8` (код цэгийн дараалал). Монгол эрэмбийг зөвхөн `COLLATE "mn-x-icu"`-ээр тодорхой хэрэглэнэ. ICU сангийн хувилбар солигдвол (OS эсвэл image шинэчлэл, major upgrade) `mn-x-icu`-д тулгуурласан индексийг `REINDEX` хийж, `ALTER COLLATION "mn-x-icu" REFRESH VERSION` ажиллуулна. PostgreSQL collation-ий хувилбар зөрвөл анхааруулга өгдөг. Migrator-ийн `verify` үүнийг шалгана.

| Хувилбар | Давуу тал | Сул тал | Яагаад сонгоогүй |
|---|---|---|---|
| Зөвхөн монгол хэл | Ажил бага | Гадаад эзэмшигч, хөгжүүлэгч, ирээдүйн зах зээл | Хэрэгцээ |
| Англиар эхэлж, дараа нь монгол | Хөгжүүлэгчид хялбар | Монгол хэлний UX ба хууль ёсны маягт хойш тавигдана | P11 зарчим |
